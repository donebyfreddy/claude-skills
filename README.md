# Claude skills

My own Claude Code skills, one folder per skill. Each folder has a `SKILL.md`.

| Skill | What it does |
|---|---|
| `web-cinematica` | Premium scroll-controlled cinematic websites for real businesses (Higgsfield video, Vercel). |
| `cover-letter` | Cover letter PDF for a job offer, in my plain, direct writing style. |

## Use a skill

Copy its folder to `~/.claude/skills/` (all projects) or to `<project>/.claude/skills/` (one project):

    cp -R web-cinematica ~/.claude/skills/

## Add a new skill

Create `<skill-name>/SKILL.md`, add a row to the table above, commit and push.
